# Using Automatos Go

For people who use the app: what each screen does and how to use it. How the app is built, and how
to run your own server for it, is in the [technical docs](../README.md).

Each page describes the app on `main`, which is what the next build or over-the-air update ships.
A page says so when part of it needs something the server has to switch on.

## Pages

- [Arcade](arcade.md): Automatos as a 16-bit role-playing game. Choosing it, the handheld home, Quests,
  Inventory, Auto and PAUSE, Options, and Auto's brief, ideas and approvals.
- [Auto, on your own initiative](proactive-auto.md): the daily brief, Auto's suggestions, approvals
  and what Auto depends on, as the phone shows them.
- [Candy](candy.md): the Candy style, its four views, Make it sweet and Pause.
